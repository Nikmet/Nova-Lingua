# Nova Lingua — дизайн-система

Портфолио-проект EasyBusiness: лендинг школы иностранных языков и админка администратора (заявки, расписание) на одном наборе токенов. Реализация — **shadcn/ui (new-york) + Tailwind v4**, токены в OKLCH.

> Живая версия со всеми компонентами и обеими темами: [`design-system.html`](./design-system.html)

---

## 1. Design read

Премиальный лендинг для взрослых учеников плюс рабочая админка администратора. Язык — спокойный корпоративный минимализм: одна кобальтовая ось на холодной нейтрали, геометрический гротеск, движение только как отклик на действие.

| | Лендинг | Админка |
|---|---|---|
| Регистр | Brand (дизайн и есть продукт) | Product (дизайн обслуживает продукт) |
| Аудитория | Первое касание, решение «прийти или нет» | Ежедневная рутина, десятки операций в день |
| Плотность | Низкая, `py-24`…`py-32` между секциями | Средне-высокая, `py-4`…`py-6` |
| Движение | Появление секций, отклик кнопок | Только отклик, никакой хореографии |

Обе поверхности используют **один набор токенов**. Различаются плотностью и количеством движения, не палитрой и не гарнитурами.

### Сцена, определившая тему

Разработчик открывает спецификацию на 27-дюймовом мониторе в освещённом офисе, чтобы скопировать значение токена, и он же отправляет ссылку потенциальному клиенту как пример работы. Дневной свет плюс документ плюс необходимость точно считывать значения → **светлая тема по умолчанию**. Тёмная реализована полностью, потому что система обязана её поддерживать, а страница обязана это доказать.

## 2. Цвет

**Стратегия: Committed, одна хроматическая ось.** Всё, что не является состоянием, это либо кобальт, либо нейтраль, тонированная в кобальт. Второго бренд-цвета в системе нет.

Все значения заданы в OKLCH: шкала строится по воспринимаемой светлоте, поэтому ступени идут ровно, а хроматичность падает к краям диапазона и цвет не «горит».

### 2.1 Cobalt — выведен из логотипа

Шкала не подобрана заново: `500` и `800` взяты пипеткой прямо из SVG логотипа, остальные ступени интерполированы вокруг них.

### 2.3 Состояния

Три семантических цвета, каждый с мягким фоном. Это единственные оттенки вне кобальтовой оси, и они допустимы только как статус, никогда как декор.

| Состояние | Foreground | Soft background | Домен |
|---|---|---|---|
| Success | `oklch(43.3% 0.0792 161.9)` | `oklch(95.5% 0.0173 159.1)` | Посещение «пришёл», занятие подтверждено |
| Warning | `oklch(47.0% 0.1000 71.2)` | `oklch(95.9% 0.0210 80.3)` | Заявка в работе, занятие перенесено |
| Destructive | `oklch(48.2% 0.1403 28.8)` | `oklch(95.0% 0.0188 25.6)` | Ученик отчислен, занятие отменено, ошибка формы |

Контраст foreground на своём soft-фоне: 6.8 / 6.2 / 6.0. Информационное состояние отдельного цвета не получает — оно берёт `--secondary` из кобальтовой шкалы.

**Правило дублирования.** Значение статуса несут иконка и слово; цвет только усиливает. Проверяется обесцвечиванием: в градациях серого бейджи обязаны оставаться различимыми. Это критично, потому что администратор сканирует таблицу заявок глазами.

### 2.4 Тёмная тема

Акцентом становится ступень **`cobalt-200`** той же шкалы: отдельного значения для тёмной темы система не заводит, берётся готовая ступень с достаточной светлотой (10.9:1 на поверхности карточки).

| Токен | OKLCH | Примечание |
|---|---|---|
| `--background` | `oklch(17.5% 0.0180 257)` | |
| `--card` | `oklch(21.0% 0.0220 257)` | |
| `--muted` | `oklch(24.5% 0.0260 257)` | |
| `--secondary`, `--accent` | `oklch(28.0% 0.0400 258)` | |
| `--border` | `oklch(31.0% 0.0330 257)` | |
| `--primary` | `oklch(84.2% 0.0684 255.3)` | `cobalt-200` |
| `--brand-deep` | `oklch(30.4% 0.1133 258.2)` | поднят до `cobalt-700`: на `cobalt-800` брендовая плитка слилась бы с фоном карточки |
| `--foreground` | `oklch(95.5% 0.0080 257)` | |
| `--muted-foreground` | `oklch(70.5% 0.0200 257)` | 7.2:1 на фоне страницы |

Мягкие фоны состояний в тёмной теме держатся на хроматичности `0.033`–`0.045`: выше начинается грязный коричневый и болотный.

### 2.5 Чего в палитре нет

- **Тёплых нейтралей.** Ранняя версия строилась на «бумажном» нейтрале тона 88 и кремовом акценте из палитры-референса. Убраны: две хроматические оси размывали бренд, а крем занимал роль, для которой уже есть кобальтовая шкала.
- **Второго бренд-цвета.** Иерархию внутри плитки задают ступень шкалы и площадь, а не новый оттенок.
- **Пастели палитры-референса.** `#A8D0EF` и `#99C3E4` дают около 2.5:1 на белом и как интерактивный цвет непригодны. Близкие к ним ступени `cobalt-200` и `cobalt-300` остались в шкале, но работают только как поверхность в светлой теме и как акцент в тёмной, где контраст обеспечен фоном.

## 3. Логотип

Файлы: [`assets/logo-ink.svg`](./assets/logo-ink.svg), [`assets/logo-inverse.svg`](./assets/logo-inverse.svg).

Это **один знак в двух цветовых версиях**, а не два логотипа. Обе версии входят в систему.

| Версия | Цвета | Где ставится |
|---|---|---|
| Основная (`logo-ink`) | `#001C40` начертание, `#0049A9` подпись | Бумага, карточка, светлая шапка, светлая тема |
| Выворотка (`logo-inverse`) | `#FFFFFF`, обе части знака | `cobalt-800` и темнее, тёмная тема |

Переключение — через `dark:hidden` / `hidden dark:block` на двух `<img>`, чтобы знак следовал за темой автоматически. Минимальная ширина 104 px: ниже подпись под вордмарком перестаёт читаться и её следует убирать.

## 4. Типографика

| Роль | Гарнитура | Почему |
|---|---|---|
| Display, заголовки от 24 px | **Montserrat Alternates** 600/700 | Характерные альтернативные знаки перекликаются с геометрией логотипа. На мелких кеглях мешают чтению, поэтому только заголовки |
| Интерфейс, текст, цифры | **Montserrat** 400/500/600 | Нейтральный геометрический гротеск, полная кириллица, хорошо держит плотные формы и таблицы |
| Цифры | Montserrat + `font-variant-numeric: tabular-nums lining-nums` | Время, цены, даты в таблицах выравниваются по разрядам без отдельной моногарнитуры |
| Технические строки в документации (имена токенов, HEX) | системный `ui-monospace` | Служебный слой самой спецификации, не часть бренда |

Антиква не используется: бренд образовательный, не издательский и не винтажный.

### 4.1 Futurespore Cyrillic — рассмотрен, не принят

Файл сохранён в [`fonts/`](./fonts/) вместе с лицензией. В систему не вошёл:

- одно начертание, только прописные, без курсива — иерархию не строит;
- роль вордмарка уже занята SVG-логотипом, вторая марка ей противоречила бы.

Если гарнитура понадобится, единственное осмысленное применение — разовый акцидентный блок вне основной иерархии. Лицензия CC BY-SA 4.0 требует указания авторства (Andrew Young, Denis Ignatov) везде, где шрифт используется публично.

## 5. Форма

### 5.1 Радиус

Три ступени, роль определяет ступень. Скруглений-таблеток нет: они спорят с квадратными модулями бенто-сетки.

| Элемент | Радиус | Токен |
|---|---|---|
| Плитка бенто, секция | `24px` | `--radius-tile` |
| Карточка, вложенный блок, изображение | `12px` | `--radius-xl` |
| Кнопка, поле, бейдж, строка меню | `8px` | `--radius-lg` (= `--radius`) |
| Тултип, мелкий поповер | `6px` | `--radius-md` |

Базовая переменная shadcn `--radius: 0.625rem`; остальные ступени выводятся через `calc()`.

### 5.2 Тень

Тонирована в `cobalt-800`, не в чёрный: на холодной нейтрали чёрная тень сереет и грязнит поверхность.

```css
--shadow-xs: 0 1px 2px 0 oklch(23.1% 0.0771 255.4 / .07);
--shadow-md: 0 4px 12px -2px oklch(23.1% 0.0771 255.4 / .12),
             0 2px 4px -2px  oklch(23.1% 0.0771 255.4 / .07);
--shadow-lg: 0 12px 32px -8px oklch(23.1% 0.0771 255.4 / .20),
             0 4px 8px -4px   oklch(23.1% 0.0771 255.4 / .10);
```

`xs` — кнопка и поле, `md` — поповер и дропдаун, `lg` — тост и модалка. В админке карточки живут на границе, а не на тени: плотный список из теней превращается в шум.

### 5.3 Плотность

Базовая единица 4 px. Отступ внутри плитки зависит от её размера: крупная плитка получает `28`–`40px`, мелкая `20`–`28px`. Одинаковый отступ везде — это монотонность, а не система.

### 6.1 `components.json`

```json
{
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "iconLibrary": "lucide"
}
```

Tailwind v4 не использует `tailwind.config.ts`, поэтому поле `config` пустое. `baseColor: "slate"` — ближайший встроенный пресет к холодной нейтрали; после инициализации значения заменяются блоком выше.

## 7. Компоненты

Базовый набор shadcn:

```bash
npx shadcn@latest add button badge card input label table dropdown-menu dialog tabs separator sonner select calendar
# lucide-react ставится автоматически как иконочная библиотека shadcn по умолчанию
```

Компоненты не используются в состоянии по умолчанию: радиусы и цвета приходят из токенов выше. Классовые строки менять не нужно, вся кастомизация живёт в CSS-переменных.

| Компонент | Применение в Nova Lingua |
|---|---|
| `Button` | `default` — «Записаться на бесплатное пробное» на лендинге, «Сохранить» в админке. `outline` — «Отмена». `ghost` — второстепенные действия в строке. `destructive` — «Отчислить» |
| `Badge` | Статусы Заявки, Ученика, Занятия, Посещения. Всегда иконка плюс слово |
| `Table` | Заявки, Ученики, Группы, Занятия. Разделители через `border-b` строки, без двойных границ |
| `DropdownMenu` | Действия строки таблицы под иконкой «⋯», не ряд отдельных кнопок |
| `Dialog` | Конвертация Заявки в Ученика, перенос Занятия |
| `Sonner` | Подтверждение сохранения, уведомление об отправке во ВКонтакте |
| `Input` + `Label` | Лейбл над полем, ошибка под полем, `gap-2`. Плейсхолдер никогда не заменяет лейбл |

### 7.1 Иконки

**Lucide React** — `lucide-react`, значение `iconLibrary` по умолчанию для shadcn/ui, поэтому компоненты подтягивают её без правок импортов.

```bash
npm i lucide-react
```

Одна библиотека на весь проект: смешивать наборы нельзя, разная сетка и разная посадка обводки сразу видны в одном ряду.

**Толщина обводки зависит от размера, а не задаётся глобально одним числом.** Lucide нарисован на сетке 24 px под обводку 2; при простом масштабировании тонкая линия пропадает на мелком кегле, а толстая грубит на крупном.

| Размер | `strokeWidth` | Где |
|---|---|---|
| 14–16 px (`size-3.5`, `size-4`) | `2` | Бейджи, кнопки, строки меню, поля |
| 20–24 px (`size-5`, `size-6`) | `1.5` | Пустые состояния, витрина иконок, крупные акценты |

Lucide **только штриховой**: залитых начертаний нет. Статус-бейджи поэтому строятся на контрастном фоне и слове, а не на плотности иконки. Правило дублирования из раздела 2.3 при этом не меняется, оно даже важнее: у штриховой иконки меньше визуального веса, чем у залитой.

Иконки домена:

| Сущность | Lucide |
|---|---|
| Заявка | `Mail` |
| Ученик | `CircleUser` |
| Группа | `Users` |
| Занятие | `CalendarCheck` |
| Кабинет | `DoorOpen` |
| Язык | `Languages` |
| Преподаватель | `Presentation` |
| Посещение: пришёл | `CircleCheck` |
| Посещение: не пришёл | `CircleX` |
| Перенос занятия | `RefreshCw` |
| Пробная группа | `Sparkles` |
| Привязка ВКонтакте | `Link` |
| Действия строки | `EllipsisVertical` |
| Пустой список заявок | `Inbox` |

Собственные SVG не рисуются. Если глифа нет, берётся ближайший по смыслу из Lucide либо композиция из существующих, но не самодельный контур.

### 7.2 Статусы домена

| Сущность | Статусы и вариант бейджа |
|---|---|
| Заявка | Новая (`secondary`) · В работе (`warning`) · Конвертирована (`success`) · Архив (`outline`) |
| Ученик | Активен (`outline`) · Отчислен (`destructive`) |
| Группа | Активная (`secondary`) · Архивная (`outline`) · Пробная (`outline` с иконкой в `primary`) |
| Занятие | Запланировано (`secondary`) · Перенесено (`warning`) · Отменено (`destructive`) · Прошло (`outline`) |
| Посещение | Пришёл (`success`) · Не пришёл (`destructive`) · Отменено (`outline`) |

## 8. Композиция

### 8.1 Лендинг

1. **Герой, асимметричный сплит.** Слева заголовок в две строки, подзаголовок до 20 слов, один CTA «Записаться на бесплатное пробное» и второстепенная ссылка на Квиз («Не знаю свой уровень»). Справа фотография. Верхний отступ не больше `pt-24`.
2. **Бенто «Программы».** Плиток ровно столько, сколько программ. Одна крупная на `cobalt-800`, одна средняя на `cobalt-600`, остальные на `secondary` и `muted`. Иерархия задаётся ступенью шкалы и площадью.
3. **Как проходит занятие.** Вертикальный блок: заголовок, абзац до 25 слов, три шага с иконками. Шаги называются действием («Заявка», «Пробное занятие», «Постоянная группа»), не «Этап 1/2/3».
4. **Квиз.** Клиентский self-assessment уровня A1–C1, восемь утверждений «что вы уже умеете». Результат никуда не передаётся: не поле формы, не комментарий, не часть Заявки (см. `CONTEXT.md`). Финальный экран ведёт к тому же CTA.
5. **Отзывы.** До трёх строк текста на карточку, ширина карточек неодинакова.
6. **Форма заявки.** Ровно три поля: имя, контакт, Язык.

CTA на всей странице один и формулируется одинаково везде: «Записаться на бесплатное пробное». Формулировка называет то, что человек получает, а не действие, которое он совершает.

### 8.2 Админка

- Боковая навигация 190–240 px, сворачивается до иконок: Заявки, Ученики, Группы, Расписание, Языки, Кабинеты.
- Сводка на дашборде — крупная цифра `tabular-nums` плюс подпись, на границе и лёгком `muted`, без карточки с тенью.
- Расписание — недельная сетка, внутри дня три дорожки по числу Кабинетов. Пересечение двух Занятий в одном Кабинете система не допускает, поэтому конфликт в интерфейсе не визуализируется: он невозможен.
- Индивидуальное занятие — это Группа с одним Учеником, отдельного визуального языка не получает.
- Конвертация Заявки — шаги называются содержанием: «Данные ученика», «Группа», «Уведомления».

## 9. Движение

Кривая по умолчанию `--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1)`. Без пружин, без отскока.

| Событие | Длительность | Что происходит |
|---|---|---|
| Нажатие кнопки или строки | `120ms` | `scale(0.97)` |
| Дропдаун, поповер | `150ms` | `scale(0.96)` + `opacity`, origin в триггере |
| Модалка | `220ms` | origin по центру (модалка не привязана к триггеру) |
| Тост | `250ms` вход, `160ms` выход | вход снизу, выход быстрее входа |
| Шаг Квиза | `200ms` | `translateY(8px)` + `opacity`, направление зависит от хода |
| Появление плиток бенто | `500ms`, шаг `60ms` | `whileInView`, `once: true` |
| Клавиатурное действие | нет | сочетания клавиш повторяются десятки раз в день |

Анимируются только `transform` и `opacity`. При `prefers-reduced-motion: reduce` остаётся прозрачность, движение снимается. В админке движение существует только как отклик на действие.

## 10. Доступность

- Контраст текста не ниже AA. Проверенные пары: `foreground`/`background` 17.0:1, `muted-foreground`/`background` 4.9:1, белый на `primary` 8.3:1, `primary` на `background` 8.0:1, состояния на своих soft-фонах 6.0–6.8:1.
- Статус никогда не кодируется одним цветом: иконка плюс слово, проверяется обесцвечиванием.
- Фокус-ринг виден всегда: `--ring` = `--primary`, толщина 3 px через `focus-visible:ring-[3px]`. `outline: none` без замены не применяется.
- Формы: `label` связан с полем через `htmlFor`, ошибка объявлена через `aria-describedby`, невалидное поле помечено `aria-invalid`.
- Логотип подаётся как `<img>` с осмысленным `alt`, а не фоном.
