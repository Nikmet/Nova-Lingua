# Уведомления в ВК — односторонняя рассылка, не интерактивный бот

Nova Lingua v1 не строит полноценного интерактивного бота ВКонтакте со сценариями и записью. Вместо этого админка при создании, переносе или отмене Занятия отправляет сообщение участникам (ученикам, преподавателям) через VK API — односторонняя рассылка, без Callback API, Bots Long Poll и обработки ответов пользователя. Решение принято ради упрощения v1; интерактивный бот с записью через диалог — возможное будущее расширение, требующее отдельного проектирования.

Вызов VK API выполняется синхронно внутри API-роута Next.js, без очереди и фоновых воркеров — на Vercel нет для этого готовой инфраструктуры, а объём операций (одна школа) не требует retry-механизма; при сбое Администратор видит ошибку в интерфейсе и повторяет действие вручную.
