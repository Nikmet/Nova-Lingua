# Только офлайн-формат в v1

Nova Lingua v1 не поддерживает онлайн-занятия — все Занятия проходят офлайн и обязательно привязаны к одному из Кабинетов. Онлайн-формат — отдельная бизнес-модель, которую рассматривают как будущее расширение при росте школы, а не как вариант того же Занятия. Решение принято, чтобы не усложнять на старте модель Занятия (опциональность Кабинета, иной сценарий связи с учеником) и логику уведомлений.
