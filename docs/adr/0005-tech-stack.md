# Стек: Next.js/Prisma/Postgres для админки, Vite+React для лендинга, shadcn/ui в обоих

Админка — Next.js + Prisma + PostgreSQL: нужны API-роуты, серверная логика (проверка конфликтов Кабинетов, отправка уведомлений в ВК) и реляционная модель, которая естественно ложится на связи Группа → Занятие → Кабинет. Лендинг — Vite + React, без Next.js: он в основном статический контент (программы, преподаватели, отзывы) и не нуждается в сервере — собирается в статический бандл и деплоится отдельно от админки (см. ADR 0004). Оба проекта используют shadcn/ui для визуальной согласованности и скорости вёрстки; лендинг при этом получает полноценную сборку (Vite), а не голый HTML/CSS/JS, как в более ранних черновиках.
