# Лендинг и админка — два отдельных проекта

Лендинг и админка Nova Lingua разрабатываются и деплоятся как два независимых проекта, не как один монолит с общим стеком. Лендинг — маркетинговая страница (важны производительность и SEO, минимум зависимостей), админка — полноценное веб-приложение с авторизацией, базой данных и бизнес-логикой (Группы, Занятия, Кабинеты, конфликты расписания). Единственная точка связи — форма Заявки на лендинге отправляет данные в API админки, и связь строго однонаправленная: лендинг ничего не читает из админки ни в рантайме, ни на этапе сборки (build-time запрос к базе тоже не делается — например, статистика вроде «500+ учеников» правится в коде вручную, а не тянется из Postgres при деплое). Все тексты, фото и видео на лендинге — статические ассеты сборки, обновляются через код и передеплой, а не через админку. Решение позволяет менять и деплоить лендинг независимо от админки, не тянуть в маркетинговую страницу лишний вес бэкенд-стека и не создавать риск, что падение админки утащит за собой лендинг.
